# S3 同步存储

把 Tau 的笔记、对话、附件同步到 S3 兼容的存储上，比如 AWS S3、Cloudflare R2、MinIO。换电脑或多台设备之间，都能拿到同一份数据。私有存储桶也能用，不需要开放公开访问。

## 开始使用

1. 在插件中心安装「S3 同步存储」，再到插件页的「已安装」里打开它的开关，马上就能用，不用重启。
2. 打开「设置 → 同步」，选择「同步插件」里的「S3 同步存储」。
3. 填写服务地址（Endpoint）、存储桶（Bucket）、地域（Region）和访问密钥；有的服务商要求特定的地址模式，按它的说明选择。路径前缀可以不填。
4. 保存后，就可以用检查、上传、下载和自动同步了，用法和其他同步方式一样。

以前在 Tau 里配过 S3 同步的话，配置会自动带过来，不用重新填写。

## 常见问题

**提示权限不足怎么办？** 检查访问密钥是否正确、有没有这个存储桶的读写权限，以及服务地址和地域是否填对。

**提示存储服务不支持某种写入方式？** 说明这家服务和 Tau 的同步方式不完全兼容。为了不覆盖你的数据，同步会停下来，不会强行写入。请记下报错信息反馈给我们。

**能和别的知识库共用同一个位置吗？** 不要。每个知识库请用单独的存储位置（可以用「路径前缀」区分），否则数据会互相覆盖。

**停用插件会删掉数据吗？** 不会。你的配置和已经同步上去的数据都会保留，重新启用就能接着用。正在同步时不能停用或卸载插件，等同步结束再操作。

## 小提醒

- 需要 Tau 0.59.0 或更高版本。
- 访问密钥相当于存储的钥匙，不要发给别人，也不要贴在截图或问题描述里。
