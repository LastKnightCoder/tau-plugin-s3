# S3 同步存储

把 Tau 的笔记、对话和附件同步到 S3 兼容的存储上，比如 AWS S3、Cloudflare R2、MinIO。换电脑或在电脑与手机之间切换时，都能拿到同一份资料库数据。私有存储桶也能直接用，不需要开放公开访问。

## 开始使用

1. 在插件中心安装「S3 同步存储」，再到插件页的「已安装」里打开开关。
2. 打开插件详情的「设置」。
3. 填写「Access Key ID」、「Secret Access Key」、「Bucket」和「区域」。使用 R2、MinIO 等兼容 S3 的服务时再填写「服务地址」；如果服务商要求特定的「地址模式」，按它的说明选择；「目录」可留空。
4. 保存并测试连接后，到「设置 → 同步」选用此服务，即可检查状态、上传、下载或开启自动同步。保存配置不会自动切换当前同步服务。

## 常见问题

**提示权限不足怎么办？** 检查访问密钥是否正确、有没有这个存储桶的读写权限，以及「服务地址」和「区域」是否填对。

**提示存储服务不支持某种写入方式？** 说明这家服务和 Tau 的同步方式不完全兼容。为了不覆盖你的数据，同步会停下来，不会强行写入。请记下报错信息反馈给我们。

**能和别的资料库共用同一个位置吗？** 不要。每个资料库请使用单独的存储位置（可以用「目录」区分），否则数据会互相覆盖。

**停用插件会删掉数据吗？** 不会。你的配置和已经同步上去的数据都会保留，重新启用就能接着用。正在同步时不能停用或卸载插件，等同步结束再操作。

## 小提醒

- 支持电脑与手机；如果同时装了资源上传插件，两边的账号分开填写，互不影响。
- 访问密钥相当于存储的钥匙，不要发给别人，也不要贴在截图或问题描述里。
