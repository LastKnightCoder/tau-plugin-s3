# S3 同步儲存

將 Tau 的筆記、對話與附件同步至相容 S3 的儲存服務，例如 AWS S3、Cloudflare R2、MinIO。更換電腦或在電腦與手機之間切換時，都能取得同一份資料庫資料。私人 Bucket 也可直接使用，無須開放公開存取。

## 開始使用

1. 在外掛中心安裝「S3 同步儲存」，再到外掛頁的「已安裝」裡開啟開關。
2. 開啟外掛詳情的「設定」。
3. 填寫「Access Key ID」、「Secret Access Key」、「Bucket」與「區域」。使用 R2、MinIO 等相容 S3 的服務時再填寫「服務位址」；若服務商要求特定的「網址模式」，請依其說明選擇；「目錄」可留空。
4. 儲存並測試連線後，前往「設定 → 同步」選用此服務，即可檢查狀態、上傳、下載或開啟自動同步。儲存設定不會自動切換目前使用的同步服務。

## 常見問題

**提示權限不足怎麼辦？** 請檢查存取金鑰是否正確、是否具備此 Bucket 的讀寫權限，以及「服務位址」與「區域」是否填寫正確。

**提示儲存服務不支援某種寫入方式？** 表示該服務與 Tau 的同步方式不完全相容。為避免覆蓋你的資料，同步會自動停止，不會強行寫入。請記下錯誤訊息並回報給我們。

**可以和其他資料庫共用同一個儲存位置嗎？** 不要。請為每個資料庫使用獨立的儲存位置（可透過「目錄」區分），否則資料會互相覆蓋。

**停用外掛會刪除資料嗎？** 不會。你的設定與已同步的資料都會保留，重新啟用就能繼續使用。正在同步期間無法停用或解除安裝外掛，請待同步完成後再操作。

## 小提醒

- 支援電腦與手機；如果同時安裝了資源上傳外掛，兩邊的帳號分開填寫，互不影響。
- 存取金鑰等同於儲存空間的鑰匙，不要發給別人，也不要貼在截圖或問題描述裡。
